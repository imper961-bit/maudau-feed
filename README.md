# maudau-feed

XML-фиды (структура YML) для импорта товаров в маркетплейс MAUDAU.

- `feed_test.xml` — тестовая партия, 2 товара (проба модерации)
- `feed_full.xml` — полный каталог, 103 товара

Формат — по техническим требованиям MAUDAU: раздел «Товари → Імпорт товарів (XML)».
Файлы генерируются скриптом, ссылка статическая.
